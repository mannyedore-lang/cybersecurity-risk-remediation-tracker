# Cybersecurity Risk & Remediation Tracker

A program-management artifact set for coordinating cybersecurity remediation across technical owners, business stakeholders, and governance forums.

## Demonstrates

- Risk scoring
- Control-gap tracking
- Remediation ownership
- Due-date governance
- Executive escalation
- Evidence readiness
- Security program reporting

## Files

- `data/security_findings.csv`
- `src/risk_summary.py`
- `governance/security_program_cadence.md`
